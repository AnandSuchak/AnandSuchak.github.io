Abstract

Enterprise Model Context Protocol (MCP) agents frequently expose large, deeply constrained JSON Schema specifications that inflate prompt token budgets. While lazy schema resolution seeks to mitigate context bloat, Learned Adaptive Schema Resolution (LASR-MCP) operates by pruning upfront schemas and dynamically injecting violated constraints upon validation failure.

In this paper, we present a rigorous empirical and theoretical evaluation of LASR-MCP (mcp-inventory-bench v2.0.3) across N=3,840 completed trials across 32 tasks, six experimental arms, and 20 fixed-seed executions per task-arm pair (7,860 response-bearing API invocations on gemini-3.5-flash-lite at temperature 0.2, alongside 154 client transport retries). Using provider-reported prompt-plus-candidate (P+C) token usage from usageMetadata and a paired task-cluster percentile bootstrap (10,000 resamples, seed 42), we characterize the Retry-Amortization Boundary in agentic tool-calling.

Key Contributions & Findings

  • Token Efficiency: LASR-MCP achieves a 31.7% reduction in recorded token consumption compared with the zero-constraint lean-schema baseline.
  • Reliability: Achieves 96.9% final structural reliability and 93.8% semantic task correctness.
  • Intent Prediction: Multi-label lexical classifier achieves an F1 score of 0.863 on constraint prediction versus 0.250 for frequency prior.
  • Theoretical Recovery Bound: Formalizes monotonic schema expansion and proves recovery bound \(K \le M - |A_0|\) under explicit admissibility conditions.
